# 桌面微信扫码 · 开源预览版

在 Mac 上操作真实 Android 手机，在独立窗口中使用手机应用，并把窗口后方的电脑二维码送给真实微信扫一扫。

**当前源码候选：v0.4.0-preview.5（App 0.4.0 / build 20），正在真机验收；已公开版本为 preview.4。已内置开源 ADB，无需额外安装。桌面相机仍有回传延迟，尚未达到参考视频或 iPhone 镜像的流畅度。**

[公开发行](https://github.com/006IDC/desktop-wechat-scanner/releases) · [安装说明](docs/INSTALL.md) · [版本记录](CHANGELOG.md)

## 现在能做什么

- 原生 macOS 手机窗口，显示真实 Android 屏幕，鼠标按下、移动、松开实时传给手机。
- USB 设备选择；无线调试的配对码与连接地址输入。内置 ADB 的无线连接已在 App 界面实测；微信独立显示和镜像已通过小米真机后端集成测试。
- 点工具栏“手机应用”，通过双击或键盘打开独立窗口；每个窗口有独立画面和输入。列表拖出入口仍待真实拖放验收，暂勿依赖。
- 微信使用专用窗口，扫码与结果保留在同一显示中，减少进出扫一扫时迁移任务。主窗口继续显示手机主屏。
- 窗口展开使用本地过渡；黄色按钮或 ⌘M 调用 macOS 原生最小化，跟随系统“神奇效果/缩放效果”和“减少动态效果”设置。
- 可选“手机锁屏时继续使用独立应用”：已在小米 Android 16 无线实测锁屏下的设置/微信画面与滑动响应；手机主屏继续锁定。
- 断开前恢复应用任务并清理本应用的临时显示/相机；失败时保留恢复记录。

## 使用

1. 将 App 移入“应用程序”后打开。需要 Apple Silicon、macOS 14.4+；手机目标 Android 16，无需 Root。
2. 点连接，选 USB 设备，或在连接窗口完成无线配对。ADB 已随包提供，用户不需要终端。
3. 需要锁屏使用时，在连接窗口勾选“手机锁屏时继续使用独立应用”（首次默认关闭，此后记住选择）。点“手机应用”，双击微信等应用打开独立窗口；列表拖出入口尚未完成验收。这里操作的是手机上的应用实例，不会复制账号或消息。
4. 微信中进入“＋ → 扫一扫”，或点独立窗口的扫码按钮；首次桌面扫码需授予此 App 屏幕录制权限。
5. 拖动微信窗口标题栏覆盖电脑二维码。识别结果仍由微信返回；后续登录、授权和支付由你决定。
6. 关闭独立窗口会把任务移回手机。收进程序坞会暂停桌面相机，恢复后点扫码继续。退出前等待清理完成。

无线配对端口与连接端口通常不同，请分别填写手机对应页面显示的值。App 会记住上次明确选择的无线设备，打开连接窗口时使用 macOS Bonjour 查找它当前的端口并尝试重连；无需重复输入配对码。发现失败时保留已存地址和手动入口。内置 ADB 本身不承担 Bonjour 发现。新建无线连接由 App 自己管理本地服务，退出时清理；现有 USB 服务继续保留。已配对信任由 Android/ADB 保存，断开 App 不等于撤销信任；可在手机无线调试的“已配对设备”中忘记此 Mac。

## 验证与限制

- 本版锁屏后端真机测试通过：主屏始终锁定，设置独立窗口滑动后中央画面变化，微信独立窗口返回真实帧；停止/重新创建直连编码流、任务恢复与自有资源清理均通过。此结果不代表任意机型、长时间稳定性或参考视频级流畅度已验证。

- 已在小米 Android 16 分别通过 USB 与 Wi-Fi 实测：读取应用目录、设置独立显示、微信独立显示与 H.264 回传、任务恢复与资源清理。无线测试明确使用网络端点，不回退到 USB；主屏与预热微信显示同时镜像、微信新帧返回及恢复清理也已验证。
- 前版已验证 App 无线选择和主屏镜像，用户截图也显示独立微信窗口已打开。本版修复拖出事件被误拦、动画窗口可能保持透明和拒绝打开时无反馈；合成测试通过，已用生产连接服务实测记住旧地址后二次连接并清理；本次已在 App 界面自动找回已记住的无线手机并选中连接，真实镜像帧持续返回；原生拖放仍需 GUI 实测，端口变化后的自动找回未通过实测。App 内配对码界面和整套扫码过渡尚未完成验收。
- 默认构建和发行使用项目持续保留的自签身份，打包校验证书身份，避免误用旧 ad-hoc 包；不修改系统信任或授权数据库。两个合成构建的身份连续性及异证书拒绝已验证，本机安装版实际录屏权限已恢复；同一证书从 build 16 → 18 → 19 更新后，实际权限均保留为 true，未重新修改 TCC。build 18 已实际采集送帧；这不是新 Mac 或其他证书迁移的保证。
- 拖出入口是本 App 的“手机应用”列表；尚不支持直接抓取手机桌面镜像里的任意图标拖出。
- 最多四个普通应用窗口，加一个微信窗口；同一包复用一个窗口。应用可能拒绝虚拟显示或保留手机显示，依机型和应用而异。
- 扫码期间窗口浮在网页上并可加入其他应用的台前调度窗口组，退出扫码后恢复普通窗口；相机中央区域直接透出本地桌面，顶部与底部保留真实微信画面和触控；二维码识别与结果仍走真实手机微信。build 19 实际界面已连接无线手机并打开扫一扫，修复后的黑条消失；切到测试网页时扫码窗保持展开，暂停恢复普通窗口层级、重开继续采集已验证。连续拖动尚未验证：测试工具对产品及普通测试窗的拖动均未产生实际位移；最终扫码结果验收又被测试页窗口捕获故障阻塞，不能据此承诺参考视频级流畅度。
- 首次调试授权及每次手机重启后，需要在手机上正常解锁一次。独立锁屏模式仅对本次临时应用窗口生效，要求 ROM 支持并已授予 shell 相应系统权限；不支持时明确失败，不改变手机主屏密码、锁态或锁屏时间。主屏镜像仍需正常解锁。音频、剪贴板和电脑键盘输入尚未实现。
- 仅 arm64，持续自签身份、未获 Apple Developer ID 签名或公证；旧 ad-hoc 版本迁移仍需要一次录屏授权。本机两次同证书更新已保留实际授权；新机器安装和其他签名迁移尚未验证，不应反复清空系统权限记录。

## 构建与许可证

```sh

python3 scripts/build_app.py
python3 scripts/package_release.py
```
