# 桌面微信扫码 · 开源预览版

在 Mac 上操作真实 Android 手机，把手机应用拖出为独立窗口，并把窗口后方的电脑二维码送给真实微信扫一扫。

**当前预览版：v0.4.0-preview.3（App 0.4.0 / build 14）。已内置开源 ADB，无需额外安装。桌面相机仍有回传延迟，尚未达到参考视频或 iPhone 镜像的流畅度。**

[公开发行](https://github.com/006IDC/desktop-wechat-scanner/releases) · [安装说明](docs/INSTALL.md) · [版本记录](CHANGELOG.md)

## 现在能做什么

- 原生 macOS 手机窗口，显示真实 Android 屏幕，鼠标按下、移动、松开实时传给手机。
- USB 设备选择；无线调试的配对码与连接地址输入。内置 ADB 的无线连接已在 App 界面实测；微信独立显示和镜像已通过小米真机后端集成测试。
- 点工具栏“手机应用”，把列表中的应用拖到窗口外独立打开，也支持双击/键盘打开；每个窗口有独立画面和输入。
- 微信使用专用窗口，扫码与结果保留在同一显示中，减少进出扫一扫时迁移任务。主窗口继续显示手机主屏。
- 窗口展开使用本地过渡；黄色按钮或 ⌘M 调用 macOS 原生最小化，跟随系统“神奇效果/缩放效果”和“减少动态效果”设置。
- 断开前恢复应用任务并清理本应用的临时显示/相机；失败时保留恢复记录。

## 使用

1. 将 App 移入“应用程序”后打开。需要 Apple Silicon、macOS 14.4+；手机目标 Android 16，无需 Root。
2. 点连接，选 USB 设备，或在连接窗口完成无线配对。ADB 已随包提供，用户不需要终端。
3. 点“手机应用”，拖出或双击微信等应用。这里操作的是手机上的应用实例，不会复制账号或消息。
4. 微信中进入“＋ → 扫一扫”，或点独立窗口的扫码按钮；首次桌面扫码需授予此 App 屏幕录制权限。
5. 拖动微信窗口标题栏覆盖电脑二维码。识别结果仍由微信返回；后续登录、授权和支付由你决定。
6. 关闭独立窗口会把任务移回手机。收进程序坞会暂停桌面相机，恢复后点扫码继续。退出前等待清理完成。

无线配对端口与连接端口通常不同，请分别填写手机对应页面显示的值。App 会记住上次明确选择的无线设备，打开连接窗口时使用 macOS Bonjour 查找它当前的端口并尝试重连；无需重复输入配对码。发现失败时保留已存地址和手动入口。内置 ADB 本身不承担 Bonjour 发现。新建无线连接由 App 自己管理本地服务，退出时清理；现有 USB 服务继续保留。已配对信任由 Android/ADB 保存，断开 App 不等于撤销信任；可在手机无线调试的“已配对设备”中忘记此 Mac。

## 验证与限制

- 已在小米 Android 16 分别通过 USB 与 Wi-Fi 实测：读取应用目录、设置独立显示、微信独立显示与 H.264 回传、任务恢复与资源清理。无线测试明确使用网络端点，不回退到 USB；主屏与预热微信显示同时镜像、微信新帧返回及恢复清理也已验证。
- 前版已验证 App 无线选择和主屏镜像，用户截图也显示独立微信窗口已打开。本版修复拖出事件被误拦、动画窗口可能保持透明和拒绝打开时无反馈；合成测试通过，已用生产连接服务实测记住旧地址后二次连接并清理；原生拖放与自动重连仍需 GUI 实测。当前局域网能发现 Bonjour 服务，但地址解析超时；系统工具复核一致，端口变化后的自动找回未通过实测。App 内配对码界面和整套扫码过渡尚未完成验收。
- 录屏权限可能出现系统设置已开启、进程仍未获得授权的情况；刷新权限提示不等于修复系统授权记录。本版保留该限制，不宣称授权问题已解决。
- 拖出入口是本 App 的“手机应用”列表；尚不支持直接抓取手机桌面镜像里的任意图标拖出。
- 最多四个普通应用窗口，加一个微信窗口；同一包复用一个窗口。应用可能拒绝虚拟显示或保留手机显示，依机型和应用而异。
- 桌面相机走 Mac → 手机微信 → Mac 回传，仍可能卡顿；未使用本地假扫码界面替代真实微信。
- 需要手机解锁与调试授权；不绕过锁屏。音频、剪贴板和电脑键盘输入尚未实现。
- 仅 arm64，ad-hoc 签名、未公证；升级可能需要重新授权录屏。不应反复清空系统权限记录。

## 构建与许可证

准备 Xcode Command Line Tools 与 Python 3.12+：

```sh
python3 scripts/bootstrap.py
python3 scripts/build_app.py
python3 scripts/package_release.py
```

构建前提交源码；App 记录准确 commit。ADB 从固定开源源码构建，工具和源码归档校验 SHA-256，缓存放 `.local/`；scrcpy server 固定官方 5.0.1。发行物位于 `build/release/0.4.0-preview.3/`，不覆盖旧版。构建默认不替换已安装 App。
