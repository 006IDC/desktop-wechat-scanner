# 安装与连接

从 [GitHub Releases](https://github.com/006IDC/desktop-wechat-scanner/releases) 下载相应版本 DMG/ZIP，核对同版本 SHA256SUMS.txt。当前预览版为 0.4.0-preview.4；旧 0.3.2 包仍需要外部 ADB，不要混用说明。仅 Apple Silicon、macOS 14.4+。

新构建的 App 名称为 MiraDroid（原名“桌面微信扫码”）。将 App 拖入 Applications。ZIP 用户先解压；不要从 DMG 内长期运行。升级前断开并退出旧实例，使用一个版本即可；改名沿用原 Bundle ID、签名身份及偏好/恢复路径，不迁移或清空系统录屏授权。

## 开发者验证提示

已公开的 preview.4 及更早预览包为 ad-hoc 签名。preview.5 源码候选改为持久自签身份，尚在验收；两者均未获 Apple Developer ID 签名或公证。若 macOS 阻止打开，先核对来源与校验值，再按 [Apple 官方指引](https://support.apple.com/102445) 在“系统设置 → 隐私与安全”使用“仍要打开”。保持 Gatekeeper 开启。企业策略可能禁止运行。

## ADB 已内置

0.4.0 包含从 android-tools 37.0.0 开源源码构建的 ADB，无需 Homebrew、SDK 或终端。App 优先使用自带工具；源码开发版缺少随包资源时保留外部工具选择入口。完整对应源码、依赖许可证、构建配方与哈希位于 `Contents/Resources/adb/`。

## USB

手机开启开发者选项及 USB 调试，接数据线、解锁，允许此 Mac 调试。App 点连接，选择已授权设备。小米可能还需要“USB 调试（安全设置）”。Android 16 是目标环境；无需安装测试 APK。

## 无线

1. Mac 和手机连同一个网络，手机打开“开发者选项 → 无线调试”。
2. 选“使用配对码配对设备”，把该页面的地址、端口和六位配对码填入 App 的配对区。
3. 返回手机无线调试主页，将主页的连接地址和端口填入 App 的连接区，点“建立无线连接”。这通常不是刚才的配对端口。
4. 在设备列表中明确选中手机，点“连接所选手机”。App 记住这次选择，下次打开连接窗口会尝试找回同一手机。

日常连接无需重新配对或每次手填：保持同一网络和无线调试开启，App 会通过 Bonjour 查找已记住的手机端口；也可点“查找无线设备”。若网络屏蔽 Bonjour 或手机关闭无线调试，可手动填写一次当前连接地址。连接建立后仍需选择手机，避免打开其他设备。

配对码只经标准输入交给 ADB，提交后清空，不进入参数或日志。Android/ADB 会保留此 Mac 的配对信任。App 断开时清理自己的会话并断开所选无线地址；若要撤销信任，在手机“无线调试 → 已配对设备”中忘记此 Mac，或关闭无线调试。

地址变化且上次会话未清理时，本版本不会猜测新地址属于同一设备；先恢复上次连接完成清理。内置 ADB 已完成小米无线配对；App 内无线连接选择与主屏镜像已验证。独立微信镜像已通过后端集成，用户截图显示微信窗口打开；新版已在界面自动找回已记住的无线手机并连接；拖放、端口变化后的自动重连及 App 内配对界面仍待完整 GUI 验收。新建无线连接使用 App 自有本地服务，不停止已有 USB 服务。首次访问局域网时，按 macOS 提示允许本 App 的本地网络权限。

## 手机锁屏时使用独立应用

在连接窗口勾选“手机锁屏时继续使用独立应用”，再连接手机。首次默认关闭，之后会记住选择；仅在信任这台 Mac 时开启。手机主屏锁定后，微信等独立窗口继续显示和接受鼠标操作，主屏镜像显示锁定提示。正常解锁手机后自动恢复主屏镜像。

需要已授权的调试连接、Android 16 对应系统能力，以及每次开机后至少一次正常解锁；工作资料/私密空间不在支持范围。App 检查已有权限和实际显示状态，不额外授予系统权限，不修改主屏密码或锁屏时间。不支持时关闭此选项并正常解锁使用。

## 独立窗口与扫码

点“手机应用”按钮，把列表中的应用拖到窗口外，或双击打开。普通窗口关闭前会把任务移回手机；同一应用复用一个窗口。不能把手机镜像里的任意图标直接抓到 Mac 桌面。

研究候选可在连接时勾选“桌面相机（通用）”。从应用列表打开需要的 App，再进入它自己的相机或扫一扫；原 App 窗口保持可见，旁边透明框用于选取电脑画面，停稳后持续传图。相机来源覆盖该窗口的扫码、拍照及视频；首次默认关闭，之后记住明确选择。不同 App 可能拒绝虚拟设备、代理其他应用拍照或无法明确相机归属，本候选尚未通过第三款真实 App 验收。未勾选时保留微信/支付宝兼容扫码流程。

使用桌面来源时，按 macOS 提示授予本 App 屏幕录制权限，并在提示要求时重启。旧 ad-hoc 包迁移至持续自签版本会改变一次身份；后续发行应持续使用同一证书。本机从 build 16 → 18 → 19 的同证书更新已保留实际权限；尚不能外推到新机器或更换证书。勿反复重置整个系统的录屏记录。只采集图像，不采集声音。将透明取景框拖到电脑内容上；识别结果由真实手机 App 处理。收进程序坞暂停桌面相机，恢复窗口后可继续。

黄色按钮和 ⌘M 使用系统动画。若希望“吸入”效果，可在 macOS“桌面与程序坞”选择“神奇效果”；App 不修改全局偏好。打开应用与桌面回传仍受手机性能和网络延迟影响。

## 卸载

先断开并正常退出，再移入废纸篓。手机可撤销 USB/无线调试授权；共享 ADB 信任不会因删除 App 自动撤销。本地恢复记录位于 `~/Library/Application Support/006IDC/DesktopWeChatScanner/`，不要上传。清理失败时先连接同一手机恢复，再删除本地状态。
