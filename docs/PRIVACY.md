# 隐私与数据路径

- 手机镜像经本机 ADB/USB 或已配对无线网络 返回 Mac，点击和滑动通过相同连接发给手机。
- 仅扫码期间，ScreenCaptureKit 在内存中取得所选显示器的画面，再裁切手机窗口后方矩形，排除本 App 窗口；编码后的裁切图传给连接手机的虚拟相机，由真实微信处理。不要误认为系统只允许 App 读取裁切区域；macOS 屏幕录制授权本身范围更大。
- 产品代码不保存桌面截图、手机镜像或二维码图片，不提供云上传或遥测。微信及系统自身的数据处理受它们各自的政策约束。
- 本机保存连接恢复所需的随机会话信息、设备序列号，以及不含图像的运行统计；会话记录设置为仅用户可读写。正常清理会移除恢复记录。ADB 工具路径、上次明确选择的无线连接地址和 Bonjour 服务名保存在本机偏好设置，用于下次自动查找当前端口；不保存一次性配对码。
- App 通过 ADB 创建临时虚拟显示/相机并移动用户选择的应用任务，退出时尝试恢复。崩溃、拔线或锁屏可能导致未完成清理，下次连接会尝试恢复。
- 镜像看到的微信消息和扫码结果均来自真实手机；App 不自动点击结果里的登录、授权、支付确认。
- `tests/` 和 `scripts/probe.py` 内的开发夹具可能读取或保存测试图像，**不属于日常产品的数据行为**。应在已知合成内容、受控输出目录中手动运行，不把生成物提交或上传。

- 应用列表来自手机主用户的可启动应用，只为选择独立窗口使用，不上传。恢复记录增加本次应用任务的原显示位置，便于关闭时还原。
- 无线配对码不持久化、不写日志；Android/ADB 保存工作站调试信任。断开网络连接不等于撤销配对，可在手机已配对设备列表忘记此 Mac。
- 内置工具不会改变全局程序坞动画设置，不执行全局 `adb disconnect` 或 `kill-server`。

- 可选独立锁屏模式会记住开关选择。启用后，已信任 Mac 可在手机主屏锁定时查看和操作用户打开的独立应用，主屏锁屏不能替代 Mac 本身的访问保护。仅对本次拥有的临时显示设置独立锁态，不修改主屏认证；正常退出销毁这些显示。
- 独立锁屏模式直接将自有虚拟显示输出给 Android H.264 编码器；每路视频/控制使用临时随机令牌，不持久化、不记录令牌。只支持该显示内的单指触摸与返回/主页导航，不发送电源、唤醒或解锁按键。
